### ⚽ Sistema de Campeonato de Futebol

Programa desenvolvido em **Python** para registrar e analisar o desempenho de times em um campeonato de futebol.

O sistema permite cadastrar diferentes equipes e informar a pontuação obtida em **5 partidas**, utilizando a pontuação tradicional do futebol:

- 🟢 Vitória: 3 pontos
- 🟡 Empate: 1 ponto
- 🔴 Derrota: 0 pontos

A partir dos resultados informados, o programa calcula automaticamente a quantidade de pontos, número de vitórias e percentual de aproveitamento de cada equipe.

Ao final, é exibida uma tabela com as estatísticas dos times e informações sobre o campeonato.

### 🚀 Principais funcionalidades

- ⚽ Cadastro de times
- 📝 Registro dos resultados de 5 partidas
- 🏆 Identificação do campeão
- 🥈 Identificação do vice-campeão
- 📊 Cálculo da pontuação total
- ✅ Contagem de vitórias
- 📈 Cálculo do percentual de aproveitamento
- 🔝 Identificação do time com mais vitórias
- 📉 Identificação do time com menor pontuação
- ✔️ Validação dos dados informados pelo usuário

### 🛠️ Conceitos utilizados

`Python` • `Listas` • `Tuplas` • `Dicionários` • `Loops` • `Condicionais` • `Validação de Dados`
