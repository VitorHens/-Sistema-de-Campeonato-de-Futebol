# ⚽ Sistema de Campeonato de Futebol

Programa desenvolvido em **Python** para registrar e analisar o desempenho de times em um campeonato.

## 🚀 Funcionalidades

- Cadastro de times
- Registro de resultados de 5 partidas
- Pontuação total de cada equipe
- Contagem de vitórias
- Cálculo do percentual de aproveitamento
- Identificação do campeão e vice-campeão
- Identificação do time com mais vitórias
- Identificação do time com menor pontuação
- Validação dos dados informados

## 📊 Pontuação

- Vitória: 3 pontos
- Empate: 1 ponto
- Derrota: 0 pontos

## 🛠️ Conceitos utilizados

Python • Listas • Tuplas • Dicionários • Loops • Condicionais • Validação de Dados

## ▶️ Execução

Execute o arquivo `Projeto.Py` utilizando Python 3.

## 🎯 Objetivo

Praticar lógica de programação e manipulação de estruturas de dados através de um sistema de classificação esportiva.
