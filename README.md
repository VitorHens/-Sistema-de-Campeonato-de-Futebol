# ⚽ Sistema de Campeonato de Futebol

Programa desenvolvido em **Python** para registrar e analisar o desempenho de times em um campeonato de futebol.

O sistema permite cadastrar equipes e informar a pontuação obtida em **5 partidas**, utilizando a pontuação tradicional do futebol:

- 🟢 Vitória: 3 pontos
- 🟡 Empate: 1 ponto
- 🔴 Derrota: 0 pontos

## 🚀 Funcionalidades

- Cadastro de times
- Registro dos resultados de 5 partidas
- Cálculo da pontuação total
- Contagem de vitórias
- Cálculo do percentual de aproveitamento
- Identificação do campeão e vice-campeão
- Identificação do time com mais vitórias
- Identificação do time com menor pontuação
- Validação dos dados informados pelo usuário

## 🧠 Conceitos utilizados

- Listas
- Tuplas
- Dicionários
- Laços de repetição
- Estruturas condicionais
- Entrada e validação de dados
- Formatação de resultados

## ▶️ Como executar

Com o Python instalado, execute:

```bash
python Projeto.Py
```

O programa funciona pelo terminal e solicita os dados dos times e das partidas de forma interativa.

## 🎯 Objetivo do projeto

Praticar lógica de programação e estruturas de dados em Python por meio de um sistema simples de análise de resultados esportivos.
